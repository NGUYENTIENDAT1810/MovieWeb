Milestone 1: Khởi tạo Project, Docker, PostgreSQL, Prisma & Health Check Hoàn thành
1. Task

Thiết lập nền móng kiến trúc Monorepo cho toàn bộ hệ thống Movie Web: khởi tạo NestJS Backend, Next.js Frontend, cấu hình Docker Compose cho PostgreSQL, tích hợp Prisma ORM và xây dựng endpoint kiểm tra sức khỏe GET /health.

2. Nguyên nhân thay đổi

Thực hiện bước 1 theo đúng quy trình và đặc tả trong tài liệu MOVIE_WEB_SPEC.md.

3. File đã tạo / sửa
  • package.json (cấu hình npm workspaces và script chạy/build tập trung từ thư mục gốc).
  • .gitignore, docker-compose.yml, .env.example, README.md
  • backend/package.json, backend/tsconfig.json (cấu hình typeRoots chuẩn cho monorepo), backend/tsconfig.build.json, backend/nest-cli.json, backend/.env.example, backend/.env
  • backend/prisma/schema.prisma: Định nghĩa các model User, Movie, Genre, MovieGenre, Episode, Favorite, WatchHistory.
  • backend/src/prisma/prisma.service.ts & prisma.module.ts: Module Prisma toàn cục và kiểm tra kết nối DB.
  • backend/src/health/health.controller.ts & health.module.ts: Xử lý GET /health.
  • backend/src/app.module.ts & backend/src/main.ts: Bootstrap NestJS với Swagger Docs tại /api/docs, Global Validation, CORS.
  • frontend/package.json, frontend/tsconfig.json (cấu hình typeRoots), frontend/next.config.js, frontend/tailwind.config.ts, frontend/postcss.config.js, frontend/app/globals.css, frontend/app/layout.tsx, frontend/app/page.tsx.
4. Logic thay đổi

Cấu trúc hóa thư mục dự án; tách biệt các tầng ứng dụng; cấu hình Global ValidationPipe; cấu hình Swagger OpenAPI.

5. Phạm vi ảnh hưởng

Toàn bộ kiến trúc nền tảng của Backend và Frontend.

6. API liên quan
  • GET /health: Kiểm tra trạng thái hoạt động của Backend và kết nối database.
  • GET /api/docs: Giao diện tài liệu Swagger / OpenAPI.
7. Cách kiểm thử
  • Chạy npm install trong backend và frontend.
  • Sinh Prisma client bằng npx prisma generate.
  • Build backend: npm run build.
  • Build frontend: npm run build.
  • Khởi chạy backend và gửi request tới GET /health.
8. Kết quả kiểm thử

Quá trình cài đặt dependencies, generate Prisma client, build Backend và Frontend đều diễn ra thành công không có lỗi.

Milestone 5: Authentication & JWT (Register, Login, Me & Role Guards) Hoàn thành
1. Task

Xây dựng hệ thống xác thực (Authentication) và phân quyền (Authorization) hoàn chỉnh với JWT, mã hóa mật khẩu an toàn qua bcryptjs, cấp phát token và kiểm soát quyền truy cập tài nguyên theo Role (USER / ADMIN).

2. Nguyên nhân thay đổi

Thực hiện Milestone 5 theo đặc tả trong tài liệu MOVIE_WEB_SPEC.md (Mục 9 & 18).

3. File đã tạo / sửa
  • backend/src/auth/dto/register.dto.ts & dto/login.dto.ts: DTO xác thực email và độ dài mật khẩu.
  • backend/src/auth/strategies/jwt.strategy.ts: Passport JWT Strategy giải mã token và gắn thông tin định danh user vào request.
  • backend/src/auth/guards/jwt-auth.guard.ts: Guard bảo vệ các endpoint yêu cầu đăng nhập.
  • backend/src/auth/guards/roles.guard.ts & decorators/roles.decorator.ts: Guard và Decorator kiểm tra quyền truy cập theo vai trò (ADMIN / USER).
  • backend/src/auth/decorators/current-user.decorator.ts: Custom Decorator trích xuất thông tin user từ request.
  • backend/src/auth/auth.service.ts, auth.controller.ts, auth.module.ts: Xử lý logic đăng ký, đăng nhập và lấy thông tin cá nhân.
  • backend/src/users/users.service.ts, users.module.ts: Module quản lý truy vấn thông tin người dùng an toàn.
  • backend/src/admin/admin-sync.controller.ts: Khóa bảo vệ các endpoint đồng bộ dữ liệu bằng @UseGuards(JwtAuthGuard, RolesGuard) và @Roles(Role.ADMIN).
  • backend/src/app.module.ts: Đăng ký AuthModule và UsersModule.
4. Logic thay đổi

Mật khẩu được băm bằng bcryptjs (10 rounds); không bao giờ trả về passwordHash trong response; token JWT có thời hạn 7 ngày; kiểm soát phân quyền chặt chẽ trước khi thực thi tác vụ quản trị.

5. Phạm vi ảnh hưởng

Tầng bảo mật, phân quyền và quản lý tài khoản của hệ thống.

6. API liên quan
  • POST /auth/register: Đăng ký tài khoản người dùng mới (Role: USER).
  • POST /auth/login: Đăng nhập và nhận chuỗi JWT Access Token.
  • GET /auth/me: Xem thông tin tài khoản hiện tại (Yêu cầu Bearer Token).
  • POST /admin/movies/sync/*: Yêu cầu Bearer Token và Role ADMIN.
7. Cách kiểm thử
  • Kiểm tra type-check và biên dịch TypeScript toàn bộ Monorepo qua npm run build.
